One sentence, at most 240 characters, to convince a friend who has never
coded to let an AI agent build their first app idea on make.fun.

`main.ts` (Node, standard library only, no network) writes that sentence
exactly — no trailing newline — to `/output/entry.txt`, deterministically.

The sentence:

> You don't have to code a thing: just tell make.fun, in your own words, the app you wish existed, and an AI agent will build a first version you can try tonight, so all you're agreeing to is seeing it for real.

## Run

```sh
node main.ts
```
